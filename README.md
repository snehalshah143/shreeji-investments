# Shreeji Investments - Financial Advisory SPA

A modern, responsive Single Page Application (SPA) built with React and Tailwind CSS for Shreeji Investments, a financial advisory firm based in Indapur, Pune.

## 🚀 Features

- **Multi-section SPA** with React Router navigation
- **Responsive Design** optimized for mobile, tablet, and desktop
- **Professional Styling** with navy blue and gold color scheme
- **Floating WhatsApp Integration** with dual contact numbers
- **Contact Form** with console logging and success alerts
- **Smooth Animations** and modern UI components
- **SEO Optimized** with proper meta tags

## 📱 Pages

- **Home** - Hero section with company introduction and call-to-action
- **About** - Company story, mission, vision, and core values
- **Services** - Comprehensive list of financial advisory services
- **Testimonials** - Client testimonials with carousel functionality
- **Contact** - Contact form and business information

## 🛠️ Tech Stack

- **React 18** - Frontend framework
- **React Router DOM** - Client-side routing
- **Tailwind CSS** - Utility-first CSS framework
- **Vite** - Build tool and development server
